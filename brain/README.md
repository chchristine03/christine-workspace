# Second brain

Compiled knowledge wiki, not a todo list. Tasks go in Linear.

Pattern: [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f). Agent workflow: `~/.cursor/skills/brain/SKILL.md`. How this wiki should grow: [wiki/concepts/gradual-formation.md](wiki/concepts/gradual-formation.md).

```
brain/
  raw/     immutable sources (you drop files; agents never edit)
  wiki/    LLM-maintained pages, index, log
```

Browse in Obsidian if you want graph view and backlinks. Agents compile; you curate sources and ask questions.
