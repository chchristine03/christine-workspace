# Overview

Christine's second brain: a compiled markdown wiki that sits between raw sources and questions. It started 2026-09-11 by ingesting Karpathy's [[llm-wiki]] pattern. The wiki is meant to get richer with each source and each filed-back answer, not to be a dump of chat logs.

Human job: curate sources, ask questions, judge what matters. Agent job: summarize, cross-reference, file, lint. Work tracking stays in Linear; this layer is knowledge.
